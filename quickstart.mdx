title: "Quickstart"

---

This path takes a workspace from an API key to a stored research report. The create request returns as soon as the run is accepted. Poll with a new request. Do not keep the original POST open.

## Prerequisites

- A Seneca account at [seneca.professionalaiagents.com](https://seneca.professionalaiagents.com)
- An API key from the [Developers page](https://seneca.professionalaiagents.com/developers#api-keys)
- An entitled workspace with enough credits for the panel you choose

Reads work without an active subscription. Paid research requires `entitled: true` and enough `available_credits`.

## Launch a run

<Steps>
  <Step title="Store the key">
    The secret starts with `seneca_sk_` and is shown once. Keep it in an environment variable.

    ```bash
    export SENECA_API_KEY="seneca_sk_..."
    ```
  </Step>
  <Step title="Read the account">
    ```bash
    curl https://seneca-research.fly.dev/v1/account \
      -H "Authorization: Bearer $SENECA_API_KEY"
    ```

    Confirm `entitled` is true and `available_credits` covers the panel. [Wide Research](/research/depths) reserves 15 credits.
  </Step>
  <Step title="Create research">
    `POST /v1/research` requires `Content-Type: application/json` and `Idempotency-Key`. A new run returns `202`. Store `id`.

    ```bash
    curl -sS -D - -X POST https://seneca-research.fly.dev/v1/research \
      -H "Authorization: Bearer $SENECA_API_KEY" \
      -H "Content-Type: application/json" \
      -H "Idempotency-Key: notes-drafts-001" \
      -d '{"prompt":"Should a notes app store drafts locally before syncing them to the cloud?","panel":"wide"}'
    ```
  </Step>
  <Step title="Poll until the run finishes">
    Research often takes several minutes.

    ```bash
    curl -sS https://seneca-research.fly.dev/v1/research/$RUN_ID \
      -H "Authorization: Bearer $SENECA_API_KEY"
    ```

    Stop when `status` is `completed`, `partial`, or `failed`. In-progress statuses are `queued`, `running`, and `synthesizing`.
  </Step>
  <Step title="Read the report">
    Quote the URL so the shell does not treat `?` as a pattern.

    ```bash
    curl -sS "https://seneca-research.fly.dev/v1/research/$RUN_ID/result?detail=compact" \
      -H "Authorization: Bearer $SENECA_API_KEY"
    ```

    Read the finding from `report.answer`. This read does not start research and does not write a credit charge.
  </Step>
</Steps>

<Note>
  If the create response is lost, repeat the same POST with the same `Idempotency-Key`, prompt, and panel. For 24 hours the server returns the original run and does not charge again.
</Note>
