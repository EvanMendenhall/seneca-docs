Seneca submits one question to a panel of independent AI models and returns a structured report: the finding, claims, positions, disagreements, minority insights, uncertainties, attribution, and methodology.

Panel models do not browse the web, call tools, or use extended reasoning. Agreement in the report is a finding about that panel. It is not a human poll, and it is not proof that a claim is factually correct.

Call Seneca over REST at `https://seneca-research.fly.dev/v1`, or over MCP at `https://mcp.seneca.professionalaiagents.com/mcp`. Both use the same API key, panels, credit ledger, and stored report. Research is asynchronous. Create a run, poll until it finishes, then read the stored report. Original model text is a separate read.

## What a run returns

<Steps>
  <Step title="A research run">
    `POST /v1/research` accepts the question and reserves the panel price. A new run returns `202`. Poll `GET /v1/research/{run_id}` until the status is `completed`, `partial`, or `failed`.
  </Step>
  <Step title="A customer report">
    `GET /v1/research/{run_id}/result` returns the stored report. Use `detail=compact` when another model will read it. The report does not include original model text.
  </Step>
  <Step title="Individual model responses">
    List stored responses, then read one model. Download the full panel as JSONL when you need every response for your own storage and analysis.
  </Step>
</Steps>

There are no webhooks in this version. Custom model selection is not part of this API. The operational integrations are the REST API and [MCP](/mcp-server).
