# Seneca documentation

Developer documentation for the Seneca Research Platform, published with [Mintlify](https://mintlify.com).

The official documentation site is [https://docs.seneca.professionalaiagents.com](https://docs.seneca.professionalaiagents.com).

The public API is `https://seneca-research.fly.dev/v1`. The API reference is generated from `https://seneca-research.fly.dev/v1/openapi.json`. MCP is available at `https://mcp.seneca.professionalaiagents.com/mcp`.

Create API keys at [https://seneca.professionalaiagents.com/developers#api-keys](https://seneca.professionalaiagents.com/developers#api-keys).

## Preview

Install the Mintlify CLI, then run it from this directory:

```bash
npm i -g mint
mint dev
```

The preview is at `http://localhost:3000`.

## Publish

Pushes to `main` deploy to [https://docs.seneca.professionalaiagents.com](https://docs.seneca.professionalaiagents.com).
